    Informática¶

    Informática Básica — Explicação Completa e Didática

    A Informática é a área responsável pelo tratamento automático das informações por meio de computadores e dispositivos tecnológicos.

    Em concursos, “informática básica” normalmente envolve:

    computadores;

    hardware;

    software;

    internet;

    segurança;

    sistemas operacionais;

    pacote Office;

    redes.

    1. O que é um Computador?

    Computador é uma máquina eletrônica capaz de:

    receber dados;

    processar informações;

    armazenar arquivos;

    executar programas.

    Funcionamento básico¶

    Entrada → Processamento → Saída

    Entrada \rightarrow Processamento \rightarrow Saída

    Entrada

    Dados inseridos.

    Exemplos:

    teclado;

    mouse;

    scanner.

    Processamento¶

    O computador analisa os dados.

    Responsável principal: CPU.

    Saída¶

    Resultado apresentado.

    Exemplos:

    monitor;

    impressora;

    caixas de som.

    1. Hardware

    Hardware é a parte física do computador.

    Tudo que pode ser tocado.

    Exemplos:

    teclado;

    monitor;

    gabinete;

    placa-mãe;

    memória;

    HD.

    Principais componentes¶

    CPU (Processador)

    É o “cérebro” do computador.

    Funções:

    executar cálculos;

    interpretar instruções;

    controlar operações.

    Exemplos:

    Intel;

    AMD.

    Memória RAM

    Armazena dados temporariamente.

    Características:

    rápida;

    volátil;

    perde dados ao desligar.

    Mais RAM → maior capacidade multitarefa.

    HD e SSD

    Usados para armazenamento permanente.

    HD

    mecânico;

    mais lento;

    mais barato.

    SSD

    eletrônico;

    muito mais rápido;

    mais caro.

    Placa-Mãe

    Conecta todos os componentes.

    É a principal placa do computador.

    Periféricos

    Dispositivos conectados ao computador.

    Entrada:

    teclado;

    mouse;

    webcam.

    Saída:

    monitor;

    impressora.

    Entrada e saída:

    pendrive;

    touchscreen.

    1. Software

    Software é a parte lógica.

    São os programas.

    Exemplos:

    Windows;

    Word;

    navegador;

    aplicativos.

    Tipos de Software¶

    a) Software de Sistema

    Gerencia o funcionamento do computador.

    Exemplo: Microsoft Windows

    b) Software Aplicativo

    Usado pelo usuário.

    Exemplos:

    Word;

    Excel;

    navegadores.

    c) Software Utilitário

    Realiza manutenção.

    Exemplos:

    antivírus;

    compactadores;

    limpeza de disco.

    1. Sistema Operacional

    É o software principal do computador.

    Gerencia:

    arquivos;

    memória;

    programas;

    hardware.

    Principais sistemas operacionais

    Microsoft Windows

    Mais usado em computadores pessoais.

    Linux

    Muito usado em servidores.

    Android

    Celulares.

    iOS

    iPhones.

    Área de Trabalho (Desktop)

    Tela principal do sistema operacional.

    Contém:

    ícones;

    barra de tarefas;

    atalhos.

    Arquivos e Pastas

    Arquivo

    Unidade de informação.

    Exemplos:

    foto;

    vídeo;

    documento.

    Pasta

    Organiza arquivos.

    Extensões de arquivos

    Tipo Extensão

    Word .docx Excel .xlsx PDF .pdf Imagem .jpg Música .mp3

    1. Internet

    Rede mundial de computadores.

    Permite:

    comunicação;

    pesquisa;

    compartilhamento.

    Navegadores

    Programas usados para acessar sites.

    Exemplos:

    Google Chrome;

    Mozilla Firefox;

    Microsoft Edge.

    Site, Página e Homepage

    Site

    Conjunto de páginas.

    Página

    Parte individual do site.

    Homepage

    Página inicial.

    URL

    Endereço do site.

    Exemplo: https://www.google.com

    Download e Upload

    Download

    Receber arquivo.

    Upload

    Enviar arquivo.

    1. Correio Eletrônico (E-mail)

    Sistema de mensagens digitais.

    Exemplos:

    Gmail;

    Outlook.

    Campos do e-mail

    Para

    Destinatário principal.

    CC

    Cópia visível.

    CCO

    Cópia oculta.

    Anexo

    Arquivo enviado junto ao e-mail.

    1. Segurança da Informação

    Assunto muito cobrado.

    Objetivo: proteger dados e sistemas.

    Princípios da segurança

    Confidencialidade

    Somente pessoas autorizadas acessam.

    Integridade

    Informações não podem ser alteradas indevidamente.

    Disponibilidade

    Sistema deve estar acessível.

    Malware

    Programas maliciosos.

    Vírus

    Infecta arquivos.

    Worm

    Espalha-se automaticamente.

    Trojan (Cavalo de Troia)

    Parece legítimo, mas é malicioso.

    Ransomware

    Sequestra dados e exige pagamento.

    Phishing

    Tentativa de enganar usuário para roubar dados.

    Exemplo: e-mail falso de banco.

    Antivírus

    Programa de proteção contra malware.

    Exemplos:

    Windows Defender;

    Kaspersky.

    Firewall

    Controla tráfego de rede.

    Ajuda a bloquear acessos indevidos.

    Backup

    Cópia de segurança dos arquivos.

    Tipos:

    local;

    nuvem;

    externo.

    1. Computação em Nuvem (Cloud Computing)

    Armazenamento e serviços pela internet.

    Exemplos:

    Google Drive;

    OneDrive.

    Vantagens

    acesso remoto;

    sincronização;

    economia de espaço.

    1. Pacote Office

    Conjunto de programas de escritório.

    Microsoft Word

    Usado para:

    textos;

    documentos;

    formatação.

    Microsoft Excel

    Usado para:

    cálculos;

    gráficos;

    tabelas.

    Fórmulas básicas

    =SOMA(A1:A10) \qquad =MÉDIA(A1:A10) \qquad =MÁXIMO(A1:A10)

    Microsoft PowerPoint

    Usado para:

    slides;

    apresentações.

    1. Atalhos do Teclado

    Muito cobrados.

    Atalho Função

    Ctrl + C Copiar Ctrl + V Colar Ctrl + X Recortar Ctrl + Z Desfazer Ctrl + A Selecionar tudo Ctrl + S Salvar

    1. Redes de Computadores

    Conjunto de dispositivos conectados.

    Objetivo: compartilhar dados.

    Tipos de rede

    LAN

    Rede local.

    MAN

    Rede metropolitana.

    WAN

    Rede ampla (internet).

    Wi-Fi

    Rede sem fio.

    IP

    Endereço do dispositivo na rede.

    Exemplo: 192.168.0.1

    1. Navegação Segura

    Cuidados importantes:

    usar senhas fortes;

    evitar links suspeitos;

    ativar autenticação em dois fatores;

    manter sistema atualizado.

    1. Software Livre x Proprietário

    Software Livre

    Código aberto.

    Exemplo: Linux

    Software Proprietário

    Código fechado.

    Exemplo: Microsoft Windows

    1. Compactação de Arquivos

    Reduz tamanho do arquivo.

    Extensões comuns:

    .zip;

    .rar.

    Programas:

    WinRAR;

    7-Zip.

    Pegadinhas de Concurso

    RAM não armazena permanentemente

    Ela perde dados ao desligar.

    Internet ≠ Web

    Internet: rede.

    Web: serviço dentro da internet.

    Upload e download são invertidos por muitos alunos

    Upload → enviar.

    Download → receber.

    Resumo Final

    Informática básica envolve:

    computadores;

    internet;

    sistemas operacionais;

    segurança;

    Office;

    redes;

    armazenamento;

    softwares.

    A base principal é entender:

    Hardware = Parte\ física \qquad Software = Parte\ lógica
