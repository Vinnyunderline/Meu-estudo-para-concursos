# Informática


Informática Básica — Explicação Completa e Didática

A Informática é a área responsável pelo tratamento automático das informações por meio de computadores e dispositivos tecnológicos.

Em concursos, “informática básica” normalmente envolve:

computadores;

hardware;

software;

internet;

segurança;

sistemas operacionais;

pacote Office;

redes.



---

1. O que é um Computador?

Computador é uma máquina eletrônica capaz de:

receber dados;

processar informações;

armazenar arquivos;

executar programas.



---

Funcionamento básico

Entrada → Processamento → Saída

Entrada \rightarrow Processamento \rightarrow Saída

Entrada

Dados inseridos.

Exemplos:

teclado;

mouse;

scanner.


Processamento

O computador analisa os dados.

Responsável principal: CPU.

Saída

Resultado apresentado.

Exemplos:

monitor;

impressora;

caixas de som.



---

2. Hardware

Hardware é a parte física do computador.

Tudo que pode ser tocado.

Exemplos:

teclado;

monitor;

gabinete;

placa-mãe;

memória;

HD.



---

Principais componentes


---

CPU (Processador)

É o “cérebro” do computador.

Funções:

executar cálculos;

interpretar instruções;

controlar operações.


Exemplos:

Intel;

AMD.



---

Memória RAM

Armazena dados temporariamente.

Características:

rápida;

volátil;

perde dados ao desligar.


Mais RAM → maior capacidade multitarefa.


---

HD e SSD

Usados para armazenamento permanente.

HD

mecânico;

mais lento;

mais barato.


SSD

eletrônico;

muito mais rápido;

mais caro.



---

Placa-Mãe

Conecta todos os componentes.

É a principal placa do computador.


---

Periféricos

Dispositivos conectados ao computador.

Entrada:

teclado;

mouse;

webcam.


Saída:

monitor;

impressora.


Entrada e saída:

pendrive;

touchscreen.



---

3. Software

Software é a parte lógica.

Exemplos:

Windows;

aplicativos.



---

Tipos de Software


---

a) Software de Sistema

Gerencia o funcionamento do computador.

Exemplo: Microsoft Windows


---

b) Software Aplicativo

Usado pelo usuário.

Exemplos:

Word;

Excel;

navegadores.



---

c) Software Utilitário

Realiza manutenção.

Exemplos:

antivírus;

compactadores;

limpeza de disco.

7. Segurança da Informação

Assunto muito cobrado.

Objetivo: proteger dados e sistemas.


---

Princípios da segurança

Confidencialidade

Somente pessoas autorizadas acessam.

Integridade

Informações não podem ser alteradas indevidamente.

Disponibilidade

Sistema deve estar acessível.


---

Malware

Programas maliciosos.


---

Vírus

Infecta arquivos.


---

Worm

Espalha-se automaticamente.


---

Trojan (Cavalo de Troia)

Parece legítimo, mas é malicioso.


---

Ransomware

Sequestra dados e exige pagamento.


---

Phishing

Tentativa de enganar usuário para roubar dados.

Exemplo: e-mail falso de banco.


---

Antivírus

Programa de proteção contra malware.

Exemplos:

Windows Defender;

Kaspersky.



---

Firewall

Controla tráfego de rede.

Ajuda a bloquear acessos indevidos.


---

Backup

Cópia de segurança dos arquivos.

Tipos:

local;

nuvem;

externo.

Pegadinhas de Concurso

RAM não armazena permanentemente

Ela perde dados ao desligar.


---

Internet ≠ Web

Internet: rede.

Web: serviço dentro da internet.


---

Upload e download são invertidos por muitos alunos

Upload → enviar.

Download → receber.
